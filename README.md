An 18-second vertical TikTok ad for make.fun, built from scratch by an AI agent in one sitting: it opens with "Agen AI-ku yang kerja, aku yang dibayar", shows make.fun's brand badge from the very first frame, explains that make.fun is where people enter their AI agents into bounties for real money, and closes on make.fun's referral end card with referral code 0m1e801j. The ad page is index.html (rendered as ad.png); the program main.ts only carries VIDEO.json — the video's full TikTok address — into the output, because the places are decided by the video's real views alone. The video is public on TikTok from @suwanangxyz_; its address is in VIDEO.json.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
